Yeelight Candela for Homey

Connects the original Bluetooth Yeelight Candela (YLFW01YL, micro USB) directly
to a Homey with Bluetooth Low Energy and support for local SDK v3 apps.
Candela models without Bluetooth cannot be connected.

Setup
1. Charge the lamp and put the switch underneath it in the Bluetooth position.
2. Disconnect the Yeelight mobile app or other Bluetooth controllers from it.
3. Install this app on Homey, then add a device: Yeelight Candela > Candela.
4. Keep the lamp within Bluetooth range of Homey and select it from the list.

Controls
- On/off. Switching on restores the last positive brightness.
- Brightness from 1% to 100%. Setting brightness to zero switches the lamp off.
- Pattern: Steady, Candle flicker (Homey), or Breathing (Homey).
- Standard Homey light Flow cards for power/brightness, plus Set pattern.
  Selecting a pattern turns the lamp on; Steady restores its base brightness.

Patterns are software effects generated by Homey at up to one brightness write per
second. Breathing has an eight-second cycle. The brightness slider controls the
maximum effect brightness. These are not commands for the lamp's native fire
mode: no verified Bluetooth command for that mode is known. Homey and this app
must stay running for effects to continue. Turning off cancels the effect.
The selected pattern resumes on the next turn-on and after app restart if Homey
last commanded the lamp on. A Bluetooth failure marks the device unavailable;
the app retries every 30 seconds. Commands also retry a dropped connection once.
Steady/off operations release the Bluetooth connection; active patterns hold it.

Homey displays the last state commanded by this app. Physical twist controls,
native fire mode, and changes made by another controller are not synchronized.
Independent paired lamps can be controlled separately; Bluetooth mesh group
provisioning and synchronization are not implemented.

Development
npm run build       Compile TypeScript
npm run lint        Check code style
npm test            Run Bluetooth/controller tests with simulated peripherals
homey app validate  Compose, build and validate the Homey app
homey app install   Install the app on the Homey selected in the Homey CLI

Automated tests simulate Bluetooth peripherals. Also verify changes on a real
Homey and Bluetooth Candela. Verified App Store publication additionally requires
an actual support contact in .homeycompose/app.json.
